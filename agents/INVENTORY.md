# Agent inventory

One list of every reusable agent the orchestrators can use. Vendor, model and effort are chosen per assignment
(AGENTS.md section 3), never per role. Native definitions are generated by `python tools/hub.py sync`.

## Orchestrators
| Orchestrator | Instructions | Native subagents | Cross-vendor workers |
|---|---|---|---|
| Claude Code | `CLAUDE.md` -> `AGENTS.md`, `agents/orchestrators/claude-code.md` | Agent tool, `.claude/agents/*.md` | `hub.py delegate --to codex` |
| Codex | `AGENTS.md`, `agents/orchestrators/codex.md` | multi-agent, `.codex/agents/*.toml` | `hub.py delegate --to claude` |

## Shared roles (`agents/shared/`)
| Role | Does | Writes | Suggested skills | Source |
|---|---|---|---|---|
| planner | roadmap / file-level plan with acceptance and prompt sequence | plan files only | brief, investigate-first, api-and-interface-design | v1 `codex/agents/planner.toml` (queue mode dropped) |
| coder | implements one bounded slice or brief | code in the working dir | brief, surgical-patch, lean-build, safe-refactor | v1 `codex/agents/coder.toml` |
| reviewer | independent read-only review, PASS/FAIL + max 10 issues | nothing | security-and-hardening, backend-api-safety, verify-and-stop | v1 `codex/agents/reviewer.toml` + `~/.claude/agents/reviewer.md` |
| tester | runs lint/typecheck/tests, reports exactly | nothing in code | verify-and-stop | v1 `codex/agents/tester.toml` (TEAM MODE dropped) |
| doc-keeper | updates specs/docs to match the code | docs only | swc, swc-central, doc-coauthoring | v1 `codex/agents/doc-keeper.toml` |
| style-scout | writes ARCHITECTURE / PROJECT_STYLE / layers draft | `.agents/` files only | graphify | v1 `codex/agents/style-scout.toml` |
| researcher | read-only investigation, evidence-ranked answer | nothing | investigate-first, graphify | new (covers v1 investigate-first usage as an agent) |

Custom roles: `agents/custom/` (none yet). Agent instances: `work/<task>/agents/<id>.md` (`hub.py status`).
